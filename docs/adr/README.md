# Registros de decisões arquiteturais

Esta pasta reúne os *Architecture Decision Records* (ADRs) do projeto. Um ADR
registra uma decisão relevante, seu contexto e suas consequências para que a
equipe consiga compreender por que determinada solução foi adotada.

Os arquivos usam numeração sequencial e título curto, por exemplo
`0002-estrategia-de-autenticacao.md`. Depois de aceito, um ADR não deve ser
reescrito para esconder decisões anteriores; uma mudança deve ser registrada em
um novo ADR que substitui o anterior.
